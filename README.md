# Sherhan Abid | Portfolio

Personal portfolio site built with plain HTML, CSS, and JavaScript.

**Live site:** [sherhan-abid-portfolio.vercel.app](https://sherhan-abid-portfolio.vercel.app)

## Features

- Hero section with a minimal animated orb design
- Project showcase (Scalera, Thar, Kryptic, Flowlance, and others)
- Glassmorphism styling with subtle scroll and hover animations
- Contact links (LinkedIn)

## Tech stack

- HTML5
- CSS3 (custom, no framework)
- Vanilla JavaScript

## Project structure

```
index.html          Main page
style.css            All styling
script.js            Interactions and animations
assets/images/       Project screenshots used in the showcase
```

## Running locally

This is a static site with no build step. Just open `index.html` in a browser, or serve it locally:

```bash
npx serve .
```
